# 🌾 농장 클리커: 파밍 에디션 (Farm Clicker)

> 웹 브라우저에서 즐기는 중독성 있는 방치형 클리커 & 농장 경영 시뮬레이션 게임!  
> 직접 작물을 클릭해 수확하고, 일꾼을 고용하며, 현대식 농기계를 도입해 나만의 대농장을 확장해 보세요.

---

## 🎮 게임 플레이 요약

* **장르:** 방치형 클리커 / 농장 경영 시뮬레이션 (Incremental Clicker)
* **기술 스택:** HTML5, CSS3, Vanilla JavaScript (ES6+), Web Audio API
* **특징:** 외부 에셋 의존성이 없는 순수 프로시저럴 UI 및 캔버스 그래픽 구현, 모바일/데스크톱 반응형 지원

```
[ 메인 작물 클릭 & 수확 ] 
          ↓
[ 재화(골드) 획득 & 누적 ] 
          ↓
[ 자동 수확 일꾼 및 농기구(트랙터, 온실) 구매 ] 
          ↓
[ 초당 생산량(EPS) 급상승 & 신규 작물 해금 ] 
          ↓
[ 초대형 대농장 제국 건설 ]
```

---

## 🕹️ 조작법 (Controls)

| 키 / 입력 | 동작 |
| :--- | :--- |
| **마우스 좌클릭** | 메인 작물 수확, 상점 업그레이드 구매, UI 상호작용 |
| **단축키 (1 ~ 4)** | 주요 업그레이드 빠른 구매 (지원되는 경우) |
| **ESC / 창 이탈** | 자동 저장 및 메뉴 열기 |

## 🌟 핵심 게임 시스템 및 메커니즘

### 1. 경제 & 수확(Harvest) 시스템
* **클리커 수확:** 화면 중앙의 메인 작물을 클릭할 때마다 일정량의 골드(`Gold`)와 경험치가 누적됩니다.
* **크리티컬 수확:** 일정 확률로 대박 수확이 터져 평소보다 훨씬 많은 골드를 한 번에 획득할 수 있습니다.

### 2. 자동화 및 업그레이드 시스템
* **농부 고용 (Farmer):** 일일이 클릭하지 않아도 초당 자동으로 작물을 수확해 주는 일꾼을 고용합니다.
* **농기구 및 시설 확장:** 스프링클러, 트랙터, 대형 온실 등을 구매하여 초당 생산량(EPS, Earnings Per Second)을 기하급수적으로 늘릴 수 있습니다.

### 3. 작물 해금 및 성장 시스템
* 농장 레벨이 오를수록 기본 밀·감자에서 시작해 딸기, 수박, 황금 작물 등 고부가가치 작물을 순차적으로 해금할 수 있습니다.

### 4. 로컬 스토리지 자동 저장
* 게임 진행 상황(소유 골드, 구매한 업그레이드, 누적 생산량)이 브라우저의 `localStorage`에 실시간으로 저장되어 언제든 이어서 플레이할 수 있습니다.

## 📁 소스 코드 구조 분석

```text
Farm-click/
├── index.html       # 게임 메인 화면 및 HTML 구조 (Font, Tailwind/CSS 레이아웃)
├── style.css        # 게임 전용 모던 스타일링, 애니메이션, 반응형 UI 디자인
├── script.js        # 핵심 게임 루프, 상태 관리, 클릭 이벤트 및 저장 로직
└── assets/          # (옵션) 아이콘, 사운드 이펙트, 작물 이미지 폴더
```

## 🛠️ 로컬 실행 및 빌드 방법

### 1. 저장소 클론 (Clone)
```bash
git clone https://github.com/badcpu3/Farm-click.git
cd Farm-click
```

### 2. 실행 방법
* 별도의 복잡한 패키지 설치(`npm install`) 없이도 **`index.html`** 파일을 더블 클릭하여 브라우저에서 즉시 실행할 수 있습니다.
* 또는 VS Code의 **Live Server** 확장을 사용하여 로컬 서버 환경에서 더욱 쾌적하게 테스트할 수 있습니다.
